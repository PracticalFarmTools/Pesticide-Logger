Who this is for

If you keep your own book — two tunnels or a hundred named sites — this is the logger. Cab phone sends. Shop tablet is the book. No cloud seat.

If you spray other people’s farms for a living — clients, on-site signatures, a crew with roles — use a custom-applicator tool such as SprayLedger. We will not pretend to be that product.

Bring last season with you

Switching is a CSV, not a new career. In the logger: More → Reports → bring last season from Excel / Google Sheets, a SprayLedger export, or Farm Spray Pro / AgriXP. Rows land as drafts. Your state checker shows what each row still needs. We never mark an import complete and we never invent REI or PHI.

If the phone dies

There is no account, so there is no cloud copy of your book. That is the point. The shop tablet is the backup:

  1. Cab phones send logs.
  2. The shop device brings them in. Newest edits win; the other version stays in History.
  3. Also download a JSON file and keep it with the farm papers. Print the restore card from Reports.

A second device is how you beat “backed up in the cloud” without giving the book away.

Put it on the home screen

This is the app. There is not a second binary in a store. Android Chrome: menu → Install app. iPhone Safari: Share → Add to Home Screen. After the first load it works offline in the cab.
