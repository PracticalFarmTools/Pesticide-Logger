Who this is for

If you keep your own book — two tunnels or a hundred named sites — this is the logger. Cab phone sends. Shop tablet is the book. No cloud seat.

Selling your crop wholesale or retail is still My crop on my land. That is the grower record list, not a commercial-applicator license.

If you spray other people’s farms for a living — clients, on-site signatures, a crew with roles — use a custom-applicator tool. This logger is the grower’s book. We will not pretend to be that other product.

The commercial record list here only reshapes office record boxes. It is not a custom-applicator CRM.

Bring last season with you

Switching is a file you already have, not a new career. In the logger: More → Reports → Choose a CSV you already have. Use a CSV you exported from a spreadsheet or another spray-log app. The file is read on this device and is not uploaded. Rows land as drafts. Your state checker shows what each row still needs. We never mark an import complete and we never invent REI or PHI. We are not affiliated with the software you exported from.

Catch up between devices

There is no account, so there is no cloud copy of your book. That is the point. Cab and shop catch up by a file when they can see each other — AirDrop, USB, or a folder you already sync yourselves. We never store the book.

  1. After you save, cab phones send a file (one tap on the Share sheet).
  2. The shop device brings that file in. Newest edits win; the other version stays in History.
  3. On Chrome / Edge, connect a backup file on a USB stick or synced folder. Every save rewrites it; the shop reads it when it is newer.
  4. Print the restore card and tape it in the shop.
