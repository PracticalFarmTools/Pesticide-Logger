Restore, catch up, and Add to Home Screen

There is no account and no cloud copy of your book. These four jobs are how the shop tablet and a cab phone stay the book of record. We cannot recover a device we never saw.

  1. Phone in the pond. On the shop tablet: More → Reports → Bring in logs, and pick the JSON backup. Or print the restore card from Home / Reports and follow it. A full backup is one file with the farm file and photos.
  2. Catch up between devices. After you save, the cab phone offers Send a file to the shop — one tap, one JSON file (Share / AirDrop). On Chrome or Edge, Connect the shop file (USB stick or a folder you already sync). Every save rewrites it; the shop reads it when it is newer. Newest edits win; History keeps the other version. We never store the book. That is the sync: a file you can see, not a server of ours.
  3. Add to Home Screen. iPhone Safari: Share → Add to Home Screen. Android Chrome: Install when the browser offers it. After the first load, logging works offline in the cab. This origin is the app; do not download a look-alike from a store listing you did not expect.
  4. We cannot recover your book. Questions about those three jobs: practicalfarmtools@gmail.com. That mailbox is how-to, not a cloud restore.

Open the backup on this device (Files → this app) when the browser allows it. Confirm bring-in vs replace. Bring-in keeps both sets.
