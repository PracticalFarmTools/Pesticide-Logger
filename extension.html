What this is

A grower-owned spray book you can recommend without an account

Pesticide Logger is for small and mid-sized farms that used to need huge-farm software to keep application records. It runs in the browser, installs to the home screen, and keeps the farm file on the device. There is no telemetry and no record server.

  • State-shaped log. The form changes by U.S. state and private vs commercial class. Private duty is scoped (required / none / uncertain) so the app does not invent boxes.
  • Label is the law. EPA lookup, when the host provides it, is identity and status only. Crop-specific rates, REI, and PHI stay label-entered.
  • Honest badges. Complete means required fields are filled — not a compliance determination. Uncertain states and unverified private duty are named.
  • Inspector packet. Self-contained HTML. Opens on any laptop. Snapshot, not a lock. Incomplete rows are marked.
  • Cab and shop without a cloud. Phones send a file; the shop tablet brings it in. A printed restore card covers “the phone went in the pond.”

This is not WPS employer software, not California PUR / New York PRL e-file, and not a substitute for the product label or the state agency. Forward the inspector page with the packet. Growers start at the public page — pick their state, then open the logger.

If they spray other people’s farms for a living (clients, signatures, crew roles), point them at a custom-applicator tool. This one is the grower’s book.
